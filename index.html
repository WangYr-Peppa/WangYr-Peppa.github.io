关于我

我是 Peppa Wang，自动化专业本科生，辅修电子信息工程。课堂之外，我把时间花在电子设计竞赛、智能车、数学建模与机器人项目上——这些经历让我习惯在有限资源与明确目标之间做工程取舍。

技术兴趣集中在控制与信号处理、嵌入式系统，以及如何用可视化让抽象算法变得直观可感。我相信好的工程展示不仅要「能跑」，还要「能讲清楚」。

平时用 Python 与 C/C++ 写逻辑，用 STM32 与 Arduino 对接真实世界，用 VS Code 与 Linux/WSL 搭建顺手的工作流。
