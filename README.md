# Personal homepage

Source for **https://blog.peppawang.me**

A static portfolio page — plain HTML + CSS, no build step, no external
dependencies (no CDN fonts, no frameworks, no image assets).

## Deploy

GitHub Pages serves the repository root of the `main` branch. Pushing to `main`
is all that's needed; the `CNAME` file binds it to `blog.peppawang.me`.

## Files

| File | Purpose |
|---|---|
| `index.html` | The page |
| `style.css` | All styling |
| `CNAME` | Custom domain for GitHub Pages |
| `.nojekyll` | Skip Jekyll processing (no plugins used) |
